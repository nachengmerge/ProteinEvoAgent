# Sources and assistance

- GB1 data: Wu NC et al., *Adaptation in protein fitness landscapes is facilitated by indirect paths*, eLife 5:e16965 (2016), https://doi.org/10.7554/eLife.16965 ; Supplementary file 1. Preserve the paper/data attribution and source licensing notices. No imputed fitness is treated as measured.
- Base model: Meta Llama 3.1 8B Instruct, https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct . Model use is governed by the Llama 3.1 license and associated terms.
- Quantization: bartowski/Meta-Llama-3.1-8B-Instruct-GGUF, https://huggingface.co/bartowski/Meta-Llama-3.1-8B-Instruct-GGUF . GGUF weights are downloaded separately, not included in this source submission.
- Inference: https://github.com/abetlen/llama-cpp-python , version 0.3.36 official Windows Vulkan wheel. Other libraries: NumPy, pandas, SciPy, scikit-learn, XGBoost, PyTorch, Biopython-independent sequence validation, Matplotlib and ReportLab; see their original licenses.
- Chinese PDF uses locally installed Microsoft YaHei font; its font file is not distributed separately. Report regeneration script currently expects Windows font paths.
- ChatGPT/Codex assisted restoration, audit, engineering fixes, execution orchestration and report drafting. Llama generated mutation hypotheses in the experiments. Values reported as P21 results came from actual local execution; no new wet-lab assays were performed. Textual rationales are visible explanations, not verified internal model reasoning.
- P33 optional protein encoder: Meta/Facebook ESM-2 t6 8M, https://huggingface.co/facebook/esm2_t6_8M_UR50D , fixed revision c731040fcd8d73dceaa04b0a8e6329b345b0f5df; original project https://github.com/facebookresearch/esm and MIT license https://github.com/facebookresearch/esm/blob/main/LICENSE . Inference implementation uses Hugging Face Transformers; no encoder training or external fitness labels are added. The pretrained sequence corpus may include GB1 or homologs; biological sequence exclusion is not established. Weights are not bundled and had not been obtained during the P33 control phase. Synthetic random-model GPU checks are engineering evidence only.
