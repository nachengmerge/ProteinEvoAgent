# 与当前Word实验报告的对应

此提交以用户桌面《实验报告.docx》为范围，报告摘要哈希见`report_source.json`。报告文件仅作范围依据，不随源码上传或修改。

1. 第3章的预测器数据来自原P29固定评价：8个初始化，512/560条训练标签，验证14,928/测试22,393条。`results/predictor/metrics_by_panel.csv`保留原逐组指标，`metrics_mean.csv`为其平均。560条为该协议贪心追加48条，不是P34全部方法的统一训练集。
2. 第4/6章主实验为原P34：45001—45008组、六方法、每轮800候选/16次反馈、三轮，2,304事件、94真实Llama调用。每个方法从同组512条出发，后续只用自身反馈。现有代码的数值评分、候选生成和大量排序由Python/P2完成，LLM选择检验动作及短理由。
3. 第5章的普通/知识LLM主对照增加氨基酸性质与条件规则；显式`EvidenceGraph`是另外的已知证据索引实现，未作为六方法主表的独立图谱增益证据。保留其代码以对应方法说明，不把P36结果混入P34。
4. 第4章提到的自审属于另一独立面板：`grounded_designer_v2.py`和补充汇总表对应该阶段。两类审查24批次相同，均值3.7529低于集成3.8078。补充不构成正文主实验的改进结论。目标约束工程、P46扩大对照等未列入此提交。
5. 第7章两个案例是45005组普通LLM流程：FWAA第2轮与KWAA第3轮。预测来自不同轮次模型，不能当同模型配对检验；两者均为利用候选，不归功于LLM自由设计。交互页另展示45001组V54M在两背景效应方向相反的实际反馈。

`SOURCE_PROVENANCE.json`区分保留原字节的科学核心、新交付入口和归档结果。精简仅作用于GitHub当前版本，完整本机项目和旧提交仍保留；未覆盖冻结结果或重新运行历史正式实验。
